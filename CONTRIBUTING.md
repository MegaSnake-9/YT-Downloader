# Contributing

Thanks for your interest in YT-Downloader.

YT-Downloader is currently a public beta. Bug reports and cross-distribution testing are especially useful.

When reporting a bug, please include:

- YT-Downloader version;
- Linux distribution and desktop environment (or Windows version, when applicable);
- whether the session is Wayland or X11 when relevant;
- steps to reproduce;
- the relevant YT-Downloader/yt-dlp error log with private paths, cookies, tokens and other credentials removed.

For AppImage-specific problems, please also say whether the problem occurs with browser cookies/keyring integration, a normal public download, or both.

Please do not commit generated release ZIPs, AppImages, runtime `data/` directories, browser cookies, exported cookie files or personal configuration files.
