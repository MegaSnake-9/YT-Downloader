# Contributing

Thanks for your interest in YT-Downloader.

For now, the project is in early development. If you report a bug, please include:

- YT-Downloader version
- Linux distribution and desktop environment (or Windows version)
- whether the session is Wayland or X11 when relevant
- steps to reproduce
- the relevant YT-Downloader/yt-dlp error log with private paths, cookies and tokens removed

Please do not commit generated release ZIPs, AppImages, runtime `data/` directories, browser cookies or personal configuration files.
